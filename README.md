# КАБАЧОК.EXE

Нативная офлайн-игра для Android 8.0+ (API 26), Kotlin + Jetpack Compose. Интерфейс на русском, вертикальная ориентация. Подходит для Samsung с Android 8.0 и новее. Не содержит WebView, рекламы, серверов, API, авторизации, аналитики или разрешения INTERNET.

## Скачать APK

**Сборка проверена:** [успешный запуск](https://github.com/SHADrussed/kabachok-exe/actions/runs/40904972594), 6 тестов пройдено, подпись APK подтверждена. [Скачать APK в ZIP](https://github.com/SHADrussed/kabachok-exe/actions/runs/40904972594/artifacts/12911146480). На физическом телефоне приложение ещё не проверялось.

Репозиторий: https://github.com/SHADrussed/kabachok-exe

1. Откройте [Actions → Build Kabachok APK](https://github.com/SHADrussed/kabachok-exe/actions/workflows/build-apk.yml).
2. Выберите последний **успешный** запуск. При необходимости нажмите **Run workflow → main → Run workflow**.
3. В разделе **Artifacts** скачайте **KABACHOK-EXE-APK** (нужен вход в GitHub).
4. Распакуйте ZIP. Внутри находится **KABACHOK-EXE-1.0-debug.apk**.
5. Откройте APK на Samsung через «Мои файлы» и разрешите установку из этого источника, если Android попросит.

Статус проверки и ограничения описаны в [BUILD_STATUS.md](BUILD_STATUS.md). Красный запуск означает ошибку; используйте только APK из успешного запуска. Артефакты хранятся 30 дней, затем можно повторить сборку.

Debug APK подписывается автоматически. Разные GitHub runner могут использовать разные debug-ключи: для обновлений с сохранением прогресса потребуется постоянный ключ подписи. Не удаляйте установленную игру, если хотите сохранить её локальный прогресс.

Через ADB, при включённой USB-отладке:

```sh
adb install -r KABACHOK-EXE-1.0-debug.apk
```

## Локальная сборка

Версии: Gradle 8.9, Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Compose BOM 2024.12.01, JDK 17 (рекомендуется), compile/target SDK 35, min SDK 26.

1. Установите Android Studio и через SDK Manager установите Android SDK Platform 35 и Build Tools 35.0.0.
2. Откройте корневой каталог проекта в Android Studio. Выберите Gradle JDK 17. IDE создаст `local.properties` с путём к SDK. Альтернатива — переменная `ANDROID_HOME`.
3. На Linux/macOS выполните:

   ```sh
   chmod +x gradlew
   ./gradlew testDebugUnitTest lintDebug assembleDebug
   ```

4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

В репозитории находится официальный Gradle Wrapper 8.9, включая `gradle-wrapper.jar`, Linux/macOS-скрипт `gradlew` и Windows-скрипт `gradlew.bat`. Исходник wrapper: тег `v8.9.0` репозитория `gradle/gradle`; лицензии находятся в `gradle/GRADLE-LICENSE`. На Windows используйте `gradlew.bat testDebugUnitTest lintDebug assembleDebug`.

Для сборки требуется интернет, чтобы скачать инструменты и Maven-зависимости. **Установленная игра работает полностью офлайн.**

## Что есть в игре

- Пять действий: «КАЧАТЬСЯ», «КАРТОШКА», «СПАТЬ», «КАРДИО», «???».
- Живой кабачок на Compose Canvas: моргание, дыхание, руки, ноги, мимика, гантели, бег, танец, сонный колпак. Пять стадий мускулатуры; пороги 4, 12, 30 и 60 тренировок.
- 39 реплик действий, 8 реплик событий, реплики касаний и секретов.
- Восемь событий: НЛО, инверсия гравитации, дискотека, картофельный дождь, корона, призрак салата, проверка агронома, сбой матрицы. Кнопка ??? всегда вызывает событие, прочие действия — с вероятностью 1/12.
- Счётчик абсурда вместо калорий. «Заряд дурью» влияет на отображаемое состояние и не блокирует действия: никакого ожидания или покупок.
- 14 достижений, всплывающие награды, конфетти, пиксельные детали, кислотная палитра, собственная векторная иконка.
- Пасхалки: 7 нажатий на заголовок, 10 касаний кабачка, последовательность картошка → сон → кардио, 42 действия.
- Короткие синтезированные звуки через ToneGenerator и вибрация. Отдельные выключатели и спокойный режим без движения. Анимации приостанавливаются в фоне и при открытых диалогах.
- SharedPreferences: прогресс, найденные события, достижения, настройки и последняя реплика. Сохранение после каждого действия. Облачное резервирование отключено.
- Сброс прогресса только после подтверждения; прокрутка для небольших экранов и крупного шрифта; текстовое описание персонажа для TalkBack.

## Устройство проекта

- `Game.kt` — чистая игровая модель, реплики, события, условия достижений.
- `GameStore.kt` — локальное сохранение.
- `MainActivity.kt` — Compose UI, жизненный цикл, звуки, вибрация, настройки.
- `Character.kt` — персонаж и анимированные сцены на Canvas.
- `GameTest.kt` — шесть тестов прогрессии, ритуала, событий, пасхалок, энергии и контента.
- `.github/workflows/build-apk.yml` — сборка, тесты, lint, проверка подписи, APK-артефакт.

## Проверка на телефоне после сборки

1. Включить авиарежим, открыть игру и проверить все пять кнопок.
2. Покачаться четыре раза: должны вырасти мышцы и открыться достижение.
3. Закрыть игру через список приложений, открыть снова: счётчик и мышцы должны сохраниться.
4. Проверить сонный колпак, бег, картофельный танец и события ???.
5. Выключить звук и вибрацию; убедиться, что настройки сохраняются после перезапуска.
6. Включить спокойные анимации, открыть музей достижений, проверить прокрутку при крупном системном шрифте.
7. Нажать заголовок 7 раз; выполнить картошка → сон → кардио.

Этот список — план приёмки, а не заявление о выполненном тестировании на Samsung.
